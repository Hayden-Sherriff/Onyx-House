# Onyx-House

## CBA Technology & AI Leadership — Sales Intelligence

Interactive stakeholder heatmap and org chart for Commonwealth Bank of Australia (CBA), built for Cognition AI sales intelligence.

### Features

- **Org chart** with hierarchical view of CBA's technology and AI leadership
- **Stakeholder detail panel** — click any executive node to view sales intelligence, talk tracks, risk flags, and LinkedIn links
- **Strategy overview** — CBA strategic pillars, entry point priority ranking, live buying signals, and recommended actions
- **Partners view** — key system integrator and consulting partner intelligence (AWS, HCLTech, Accenture, Synechron, Mantel Group)
- **Filtering** — filter by Primary Targets, Tech & AI, Board, Divisional Tech, US Tech Hubs, India Tech Hub
- **Dark / Light theme toggle**
- **Responsive layout** — works on desktop and mobile

### Usage

Open `index.html` in any browser. No build step or dependencies required — it's a single self-contained HTML file.

```bash
# Or serve locally
npx serve .
```
